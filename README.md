# Claude responde tus mensajes de Instagram con ManyChat

Tutorial gratis en español para conectar **Claude** a Instagram con **ManyChat**: responde mensajes directos y
comentarios y lleva cada conversación a una llamada. Incluye el prompt en [`docs/prompt.txt`](docs/prompt.txt).

Hecho por [Diego Osorio](https://instagram.com/soydiegoosorio).

**[👉 Abrir el tutorial](https://diegodoc1111.github.io/bot-instagram/)**

## Fuentes verificadas (29-oct-2026)

- Integración oficial: https://help.manychat.com/hc/en-us/articles/19689792833180-Claude-integration (actualizada el
  3-dic-2025): llave en API Keys de Anthropic → Settings > Integrations → Connect Claude Account; acción de Claude con
  modelo, prompt, Last Text Input y campo personalizado para la respuesta.
- Plan Pro de ManyChat: https://help.manychat.com/hc/en-us/articles/25800228332572-Pro-plan (39 USD/mes, 29 USD/mes
  anual, 14 días gratis; integraciones y automatización con IA). El plan Essential no trae integraciones.
- Llaves de la API de Claude: https://platform.claude.com/settings/keys.
